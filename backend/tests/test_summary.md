### Known Issues

#### 1. Hypothesis Health Check Failures
**Affected Tests:**
- `tests/test_error_handling_images.py` (4 tests)
- `tests/test_image_retrieval_properties.py` (3 tests)  
- `tests/test_image_upload_auth_properties.py` (5 tests)

**Issue:** These property-based tests use function-scoped fixtures (`test_db`, `authenticated_client_factory`) which Hypothesis doesn't support well.

**Error Message:**
```
hypothesis.errors.FailedHealthCheck: uses a function-scoped fixture 'test_db'.
Function-scoped fixtures are not reset between inputs generated by `@given(...)`,
which is often surprising and can cause subtle test bugs.
```

**Solution:** Add `@settings(suppress_health_check=[HealthCheck.function_scoped_fixture])` to these tests.
